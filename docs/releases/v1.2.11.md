# v1.2.11 — Patch release

This patch updates the release version and documentation for both supported
products. Application code and dependency locks are identical to v1.2.10.

The retained DHCP client uses coordinated Hex `abyss` and `abyss_raw` 0.9.0,
with the raw package selected only in its production path. The independently
shipped Management and Worker products continue to exclude the retained client
and its raw native package. Worker provides authoritative DNS.

See the [migration details](../phase1/abyss-raw-migration.md) and
[v1.2.10 validation and known limits](v1.2.10.md). Those include six existing
Management ExUnit failures, two existing JavaScript PreserveScroll failures,
and the unchanged intermittent Worker immediate-reopen directory-lock race.
This release does not repair those baseline issues. The optional native checks
validate an adapter consumer and isolated DHCP/ARP packets, not a complete DHCP
client application release. ARM runtime and target-host deployment remain
unverified.

Version-specific archive checksums, image digests and published runtime
acceptance are recorded in the GitHub release after publication.
